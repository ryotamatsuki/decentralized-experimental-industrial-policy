# Cycle 05 — Reduction Tests

This is a Stage-2 kill screen, not a Stage-3 tournament. A fatal conceptual
reduction ends the cycle.

| Test | Result | Reason |
|---|---|---|
| R1 Standard subsidy model? | Not the closest label, but commitment is a standard demand/contract instrument | No new margin from calling demand support FCP |
| R2 Standard entry/screening? | **FATAL** | Later entrant investment/entry into a procurement contest is standard |
| R3 R&D spillovers? | Not needed | Candidate does not rely on spillovers |
| R4 Adoption/diffusion? | Not needed | Candidate is investment/entry, not diffusion |
| R5 Public procurement/demand pull? | **FATAL** | The public buyer's role is exactly demand-pull procurement |
| R6 Product design/quality choice? | Not needed | No distinct quality-choice margin |
| R7 Matching/search/platform? | Not needed | No matching/platform primitive |
| R8 Coalition formation? | Excluded | No coalition mechanism |
| R9 Vertical contracting? | **FATAL if lock-in is claimed** | Renewal, re-tender, and hold-up are standard contractual procurement |
| R10 Agglomeration/place-based competition? | Not needed | No geographic competition |
| R11 Private intermediary replication? | **FATAL** | A private buyer can make the same credible purchase commitment in the model |
| R12 Local vs national government? | **FATAL** | Replacing the public buyer with a national or private buyer leaves the mechanism unchanged |
| R13 Remove institution? | **FATAL** | Removing FCP leaves a general two-period procurement commitment model |
| R14 One known primitive explains all? | **FATAL** | Buyer commitment + supplier investment + later competition explain the result |
| R15 Relabeled standard model? | **FATAL** | The FCP label is the main proposed novelty after structural substitution |

## Kill condition

If the proposed result survives only by requiring a non-replicable public
asset, an unusual legal re-tender restriction, or an additional subsidy/data/
interoperability primitive, it is not the Stage-0 candidate and cannot be
rescued in this run.

**Result: fatal conceptual reduction; Stage 2 NO-GO.**
