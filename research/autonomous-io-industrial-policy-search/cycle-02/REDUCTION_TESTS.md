# Cycle 2 — Reduction Tests

Formal Stage 3 tournament was not run because Stage 2 was fatal.

| test | result |
|---|---|
| R1 standard subsidy | A subsidy plus an open-data condition is not enough; the core is already the data-access investment trade-off. |
| R2 entry/screening | Downstream entry is already part of data-neutrality/data-sharing theory. |
| R3 R&D spillovers | Deployment data are a newer label for a spillover/learning stock; Tong & Manea directly formalize it. |
| R4 adoption/diffusion | Adoption creates the data stock, but this does not escape learning-by-deploying theory. |
| R5 public procurement | The public condition changes the application, not the strategic data game. |
| R6 product design | Product quality/learning is already in the data-enabled learning literature. |
| R7 matching/platform | Fang & Kim and Hagiu & Wright cover access/network versions; no public-specific necessity remains. |
| R8 coalition formation | Pooling data is not a new coalition mechanism; C5/C1 cannot be reintroduced. |
| R9 vertical contracting | Data access can be contractual, but the welfare wedge is still the standard access/appropriation wedge. |
| R10 place-based policy | Regional labels would move toward frozen C5, not create a new result. |
| R11 private intermediary | A platform, standard setter, or private data intermediary can implement the same access rule. |
| R12 local versus national government | The standard result is invariant to government level. |
| R13 remove institution | The theory remains a generic data-sharing/competition theorem. |
| R14 one known primitive | Data neutrality or learning-by-deploying alone accounts for the proposed effect. |
| R15 relabeled standard model | Yes; the branch is recognizable as open/closed data or technology sharing. |

## Conclusion

The candidate is killed at Stage 2. No extra data-governance assumption may be introduced to protect it.
