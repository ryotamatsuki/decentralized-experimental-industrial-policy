# Q23 Frontier Audit — Pre-Market Engagement versus Downstream Subsidy

Date: 2026-08-28

## Verdict

**`NO-GO FOR CURRENT STAGE-3 SELECTION`**

Q23 contains a real and policy-relevant distinction between acting before the feasible supplier/solution set is fixed and subsidizing an already identified transaction. But the minimum economic formulations are too close to endogenous bidder entry, pre-contract R&D, costly information acquisition, and private-buyer supplier-engagement problems. The residual interactive problem-formulation channel is interesting but does not yet make government strategically essential.

## Research question tested

> When should public innovation policy spend resources on pre-market problem articulation and supplier engagement rather than subsidize the eventual technology transaction, when early engagement changes which suppliers enter and which solutions are offered?

## Strongest reduction

> **This is just endogenous bidder entry / information acquisition before procurement, compared with a subsidy after entry.**

This reduction is largely correct for the tractable minimum versions of Q23.

## Closest literature

### 1. Tan (1992), Journal of Economic Theory
Evidence: published abstract/model summary verified.
Classification: **`STRUCTURALLY VERY CLOSE`**.

- Competitive procurement with pre-contract R&D.
- Endogenous number of firms.
- Firms incur resources before bidding; auction design and entry interact.
- Free-entry equilibrium is explicitly characterized.

If “market engagement” operates only by making supplier participation/R&D cheaper or more profitable, Q23 is already inside this class.

### 2. Drake (2025), Journal of Public Economic Theory
Evidence: published abstract and model description verified.
Classification: **`STRUCTURALLY VERY CLOSE`**.

- Procurement auction with endogenous entry.
- Entry regulations/costs and contractual requirements alter equilibrium number of bidders and bidding behavior.

Again, an upstream instrument that simply shifts entry cost/payoff is not new.

### 3. Berkhout, Rainville, Janssen & Frenken (2026), Research Policy
Evidence: published open-access metadata/abstract and detailed empirical mechanism description verified.
Classification: **`COMPONENT OVERLAP / FRONTIER INSTITUTIONAL EVIDENCE`**.

- Market engagement during tender preparation supports demand articulation and interactive learning.
- Engagement informs suppliers about upcoming opportunities and may lead procurers to adapt tender/procurement processes.
- Different engagement formats have heterogeneous and sometimes adverse innovation effects.

This is important evidence that engagement is not a scalar subsidy, but it is empirical rather than a formal theory gap.

### 4. Innovation contest / challenge-procurement theory
Classification: **`STRUCTURALLY VERY CLOSE`** when public action changes innovator entry or pre-award effort.

### 5. Open-innovation problem-formulation literature
Classification: **`COMPONENT OVERLAP`**.

The residual candidate distinction is interactive problem formulation: suppliers do not merely enter an already specified opportunity; engagement may change the specification/problem itself and hence the set of relevant suppliers/solutions.

## Fatal-test results

| Test | Result | Assessment |
|---|---|---|
| K1: engagement = supplier entry subsidy | true in simplest version | `FATAL` |
| K2: engagement = buyer information acquisition | strong reduction | `FATAL THREAT` |
| K3: engagement = cheap talk/communication | possible in stripped version | `FATAL THREAT` |
| K4: supplier set changes only via participation cost | standard endogenous entry | `FATAL` |
| K5: quality mechanically rises with engagement | prohibited | `FATAL IF USED` |
| K6: exact ex-ante market-development vs downstream-subsidy theorem | not located | `UNRESOLVED`, not novelty evidence |
| K7: government strategically necessary | not established | `FATAL FOR CURRENT PUBLIC-POLICY FRAMING` |

## Residual distinction

The only promising residual is a co-production channel:

`early engagement -> supplier responses reveal/reframe feasible solutions -> buyer changes problem/specification -> altered supplier participation/solution set`

This is more than an entry-cost reduction. However:

1. private sophisticated buyers can also engage suppliers early;
2. formalizing problem/specification co-production would require a new information/communication or design technology;
3. that would move beyond a Stage-2 question audit into a new mechanism choice;
4. Q3 already captures a more general intermediation architecture with a stronger public multilevel assignment motivation.

## Government essentiality

Weak. Preliminary supplier engagement, design dialogue and early supplier involvement are common private-procurement practices. Public procurement adds transparency/equal-treatment/accountability constraints, but using those constraints to create the theorem would introduce a new public-specific mechanism not present in the current Q23 question.

## Welfare potential

There is a credible welfare distinction between upstream market formation and downstream transaction support, especially if upstream activity changes the option set. But with the tractable minimum structure, welfare comparisons largely become entry/search investment versus transaction subsidy comparisons already familiar from procurement and industrial-organization theory.

## Research value retained

Q23 should remain an institutional/empirical insight and a possible future non-public procurement research branch. It is not recommended over Q3 for the next theory mechanism search.

## Stage-2 status

**`Q23 = NO-GO FOR CURRENT STAGE-3 SELECTION`**

Do not rescue Q23 by adding public procurement legal constraints, strategic disclosure, endogenous problem design, or a communication game in the same branch. Such a pivot requires a fresh authorized mechanism search.
