# Sequencing Test — A1 Novelty Audit

Date: 2026-08-28

A1 is institutionally staged, but administrative sequence is not automatically an economic sequencing mechanism. The test asks whether changing the order changes supplier entry/design **without adding a new primitive**.

## Sequence A — screen -> finance -> replication

This is the closest representation of the observed programme architecture.

If S, the availability/rules of F, and the existence of R are all announced or anticipated before entry/design, the supplier chooses with all three terms in view. The later payment/diffusion dates affect implementation timing but do not create an additional strategic state under the frozen primitives.

## Sequence B — finance -> screen -> replication

If "finance first" means only that the amount/rule of support is announced before the screen, while eligibility remains known before entry/design, supplier incentives are materially the same as Sequence A. The order of administrative labels does no work.

If finance is actually paid before eligibility is resolved, a new sunk-investment/refund/option problem would arise. That primitive is not in A1 and cannot be introduced for rescue.

## Sequence C — replication commitment -> screen -> finance

A credible ex-ante commitment to downstream procurement/support could change entry/design by changing expected future value before the screen.

However:

- the parent primary-source audit verifies downstream opportunities/support, not a universal binding commitment to every initial project;
- commitment credibility would become an additional dynamic-contracting/government-commitment mechanism.

Therefore Sequence C cannot be used to save A1.

## Sequence D — screen -> finance, no replication

Removing R leaves a standard costly eligibility/performance requirement plus implementation finance. Selection/inducement can still occur through S and F.

Adding R then enlarges the market value of reusable design, a margin already present in product-design/demand-pull theory.

## Does order alter private behavior within the frozen A1 primitives?

Only if one of the following is added:

- agents learn previously unknown information between stages;
- government cannot commit to a later action;
- early expenditure is sunk before later eligibility terms become known;
- continuation depends on hidden effort/type.

All are outside the frozen A1 and several are explicitly forbidden rescue routes.

## Sequencing verdict

`SEQUENCING DOES NO INDEPENDENT ECONOMIC WORK UNDER THE FROZEN PRIMITIVES.`

This is a binding NO-GO condition under the run contract.

The institution remains staged descriptively, but the theory contribution cannot be "the sequence" unless a second mechanism is added. No such addition is authorized.
