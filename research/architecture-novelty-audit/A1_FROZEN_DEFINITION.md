# A1 Frozen Definition — Scalability-by-Design Architecture

Date: 2026-08-28
Stage: Architecture-Specific Stage 2 Novelty Kill Gate
Status at entry: `POTENTIALLY DISTINCT / REQUIRES NOVELTY AUDIT`

## Research object

A1 is frozen as the following three-block architecture only:

1. **S — Scalability / Multi-Site Eligibility.** The initial programme requires/selects projects that can be implemented at multiple sites or plausibly deployed horizontally.
2. **F — Implementation Finance.** Public support pays part of the real-world implementation, adaptation and validation cost for selected projects.
3. **R — Downstream Replication Opportunity.** After initial implementation, validated solutions may be packaged, horizontally deployed and supported at later adopters.

No fourth primitive may be introduced in this audit.

## Institutionally verified boundary

The parent architecture audit establishes that the FY2026 main Triangle Ehime route requires at least two Ehime implementation sites, provides project-specific implementation support, and connects completed/validated projects to retention, packaging and horizontal-deployment activity. Separate adopter-side support schemes for validated solutions also exist.

The following stronger statement is **not verified** and is therefore excluded:

> Every initial project receives a binding ex-ante commitment to a future replication subsidy or follow-on contract.

Accordingly, R is audited first as a downstream market opportunity / demand-support environment, not as a government commitment device.

## Candidate economic object

The only candidate object authorized for novelty testing is:

> programme architecture changes the endogenous composition or design of projects.

The conjectured direction is:

`S -> entry/design -> funded-project composition -> return to F and R -> entry/design`.

This is a conjecture, not a mechanism result.

## Two interpretations that must not be conflated

### Interpretation 1 — Type screening

Projects or suppliers already differ in scalability. S selects the scalable type; F relaxes participation; R raises expected downstream value.

**Primary fatal reduction:** standard screening/eligibility + participation transfer + downstream market-size benefit.

### Interpretation 2 — Endogenous design

The same supplier can choose a bespoke or reusable/scalable design after observing the programme architecture.

**Primary fatal reduction:** standard minimum-quality/standardization/product-design theory in which an eligibility standard and future market size alter endogenous product quality, commonality or customization.

A1 survives only if neither interpretation is structurally contained by existing formal theory and an irreducible S/F/R interaction remains.
