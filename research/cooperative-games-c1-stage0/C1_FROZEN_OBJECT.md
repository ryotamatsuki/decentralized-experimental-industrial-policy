# C1 Frozen Object

## Frozen research object

C1 asks whether coalition-composition-contingent industrial policy has an implementation capability that feasible member-level contingent transfers lack.

Comparator classes:

- coalition instrument: `s(S)`;
- individual conditional transfers: `t_i(S)`;
- target outcome: an efficient and stable coalition/coalition structure.

The audit does not assume that writing `s(S)` makes the instrument economically nonseparable.

## Fatal null

`H0`: if the relevant event `S` is observable/contractible and money is transferable, any monetary coalition grant can be allocated across members as member-specific payments conditional on the same event. Hence the accounting form of the payment does not strictly enlarge the implementation set.

## New-primitive requirement

A survivor would need a coalition-level economic object that cannot be represented as member-specific claims *without* adding an ad hoc friction merely to obtain non-equivalence.

## Prohibited rescue

Do not rescue C1 by importing private information, moral hazard, political incentives, local-information advantage, learning spillovers, generic network effects, evidence/certification design, IP/data ownership, multiple governments, arbitrary budget constraints, or bargaining complexity. C5/C7 are not part of this run.

## Stage position

Stage 0 only: question hardening and primitive/implementability audit. No formal model.
