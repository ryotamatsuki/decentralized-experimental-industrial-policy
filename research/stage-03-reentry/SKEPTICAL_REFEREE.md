# Skeptical Referee Tournament — C6 vs C3

Date: 2026-08-28

Purpose: attempt to reject both candidates before a new Stage 4 investment.

## C6 attacks

| Attack | Verdict | Reason |
|---|---|---|
| 1. This is standard signaling. | `WEAKENED` | The natural class is more precisely test/evidence design than pure signaling, but that refinement does not help novelty. |
| 2. This is standard certification. | `FATAL` | Seller/supplier-chosen certification tests and private/planner divergence are already formalized. |
| 3. This is standard information design. | `FATAL` | DeMarzo–Kremer–Skrzypacz, Shishkin and adjacent test-design work already endogenize evidence structure. |
| 4. The success-information trade-off is assumed. | `FATAL` | A raw `p(d)` versus `I(d)` trade-off would mechanically generate the desired distortion unless derived from another primitive. |
| 5. Government adds nothing strategic. | `FATAL` | Removing the sponsor leaves the core supplier-test/downstream-approval game intact. |
| 6. The model requires political payoff to work. | `FATAL AS RESCUE` | Political credit/career concerns could make the sponsor prefer visible success, but are explicitly outside the admissible baseline and would create a second mechanism. |
| 7. Industrial-policy labeling is cosmetic. | `FATAL` | Without a sponsor-specific strategic role, the local-government interpretation does not change the mechanism. |

### C6 referee decision

**REJECT / NO-GO before Stage 4.**

The empirical/program-evaluation intuition remains valuable, but the proposed theory contribution is already inside a mature information/test-design class or requires an unauthorized second margin.

## C3 attacks

| Attack | Verdict | Reason |
|---|---|---|
| 1. This is standard public/private appropriability. | `FATAL` | The policy wedge is directly who captures learning returns versus who receives spillovers. |
| 2. Two knowledge components mechanically generate the result. | `FATAL` for non-monotonicity | Opposing private/public shares can mechanically create sign changes. A one-process formulation reduces arbitrariness but reveals the standard incidence wedge. |
| 3. This is standard learning-by-doing. | `FATAL / VERY CLOSE` | Own learning, cross-firm learning, diffusion spillovers and subsidy implications are mature literatures. |
| 4. This is technology diffusion with relabeled agents. | `FATAL` for follower-learning claims | Initial adoption generating lower later adoption costs is already modeled directly. |
| 5. Supplier learning only shifts a participation constraint. | `FATAL` in the minimum skeleton | No new opponent response or strategic state is generated. |
| 6. Government adds nothing strategic. | `FATAL` | Government finances the private/social wedge; it does not create a separate feedback in the minimal setup. |
| 7. Regional fit is an ad hoc heterogeneity parameter. | `WEAKENED` | The one-process learning-share formulation avoids arbitrary region types, but does not solve the novelty problem. |

### C3 referee decision

**REJECT / NO-GO before Stage 4.**

C3 is a useful decomposition for empirical/institutional analysis but not a sufficient standalone theory mechanism under the current gate.

## Tournament decision

The research-director standard is not “pick the less damaged candidate.” Both candidates must independently satisfy the Stage 3 success test.

They do not.

- C6: sharper endogenous margin, but structurally contained by test/evidence-design theory and lacks an essential public-sponsor role.
- C3: stronger demonstration-policy interpretation, but collapses to appropriability/learning-spillover logic and lacks a new strategic response.

**FINAL REFEREE VERDICT: BOTH NO-GO.**
