# Cooperative-Game Necessity Audit

## Standard

A candidate passes only if deleting blocking/coalition structure/coalition externality/coalition-specific surplus destroys the claimed economics rather than merely changing notation.

| Candidate | Indispensable cooperative object? | Can ordinary non-cooperative model likely reproduce it? | Result |
|---|---|---|---|
| C1 | potentially: coalition-specific complementarity + blocking | yes unless instrument non-equivalence is proved | CONDITIONAL PASS |
| C2 | weak: heterogeneous team composition | yes, matching/team selection | FAIL |
| C3 | yes: core blocking | but result is cost-of-stability prior art | FAIL novelty |
| C4 | not yet | yes, dynamic R&D/adoption/licensing | FAIL |
| C5 | yes: payoff depends on rival partition | not without encoding same coalition externality elsewhere | CONDITIONAL PASS |
| C6 | weak | yes, screening/matching/mechanism design | FAIL |
| C7 | potentially: feasible blocking coalitions depend on exclusivity/multi-membership | yes through licensing unless distinct policy theorem survives | CONDITIONAL PASS |
| C8 | no | insurance/contracting | FAIL |
| C9 | no | matching/assignment | FAIL |
| C10 | no | spillover/adoption models | FAIL |

## C1 necessity condition

The cooperative object must be a **subset-specific deviation problem**. If each firm's participation decision is independent conditional on transfers, or if an individual mechanism can freely condition each transfer on the entire group state, cooperative-game language adds no economics. Stage 0 must therefore compare implementable coalition structures under explicitly justified instrument classes.

## C5 necessity condition

C5 has the clearest formal reason for a partition function: the value of joining an adopter coalition changes when rival coalitions form. But that is only a modeling necessity, not novelty. The research contribution must be a new industrial-policy comparative static or implementability result.

## C7 necessity condition

C7 uses coalition feasibility itself: exclusivity may remove future coalitions from the feasible set, while portability/open membership restores them. The weakness is that licensing and R&D-membership literatures already study exclusive/nonexclusive arrangements. The public-policy condition must do something not reducible to those private contract choices.
