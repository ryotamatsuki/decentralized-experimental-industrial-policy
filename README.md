## What changed in the reset

The reset stopped treating the policy mainly as a subsidy for an experiment. Existing institutional evidence shows that the programme also performs supplier recruitment, problem articulation, local implementation-field discovery, screening, matching, implementation management, evaluation and follow-on deployment.

Thirty new research questions were generated. Twenty were killed/deferred in the first pass; ten received a targeted mini-audit; five remain white-space finalists.

## Preferred TOP 3 research questions

### Q3 — Multilevel Innovation Intermediation

How should technology-search and matching responsibilities be divided between local and national innovation intermediaries when the value of intermediation depends jointly on problem articulation on the adopter side and market thickness on the supplier side?

### Q19 — Implementation Projects as State-Capacity Investment

When should a government undertake technology-implementation projects partly because conducting them builds its future capability to identify, screen and govern supplier–adopter matches, and when does that learning rationale instead justify excessive public project activity?

### Q23 — Pre-Market Engagement versus Downstream Subsidy

When should public innovation policy spend resources on pre-market problem articulation and supplier engagement rather than subsidize the eventual technology transaction, when early engagement changes which suppliers enter and which solutions are offered?

These questions are **not novelty-verified**. Each has an explicit fatal reduction test in `research/stage-00-reset/SKEPTICAL_REFEREE.md`.
