# Decentralized Experimental Industrial Policy

This repository records a stage-gated theory-research project on decentralized government support for private-technology experimentation.

The motivating institution is the class of programs exemplified by Triangle Ehime. Triangle Ehime is a source of institutional facts and potentially meaningful frictions; it is not the intended object of the final theory.

## Current research boundary

- Agentic Run #1 covers **Stage 0 through Stage 3 only**.
- Each stage records a canonical `GO`, `CONDITIONAL GO`, or `NO-GO` verdict and a routing label.
- A `NO-GO` stops the branch.
- Stage 3 is followed by a human hard gate even if its routing label is `GO TO MINIMAL MODEL`.
- No formal model, equilibrium derivation, theorem, manuscript, Stage 4 directory, or PR merge is authorized in this run.

Canonical workflow: [`ryotamatsuki/research-paper-workflow`](https://github.com/ryotamatsuki/research-paper-workflow), `main` at `d5c5146098d97279ad3e90342fa757f0f31c8264` when this run began.
