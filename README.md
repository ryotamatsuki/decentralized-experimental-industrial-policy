## A1 frozen bundle audited

1. **S:** multi-site / scalability eligibility;
2. **F:** public implementation finance;
3. **R:** downstream replication opportunity/support.

The institutional architecture is primary-source grounded: the FY2026 main route requires at least two Ehime implementation sites; selected projects receive implementation support; the programme connects implementation to retention/packaging/horizontal deployment and separate later-adopter support schemes exist. A universal binding ex-ante future-support entitlement for every initial project is **not verified**.

## Why A1 was killed

The dedicated novelty audit did not find one exact formal copy of the complete administrative S/F/R sequence. That was not sufficient to advance.

The operative margins reduce structurally to mature theory:

- **S / selection:** public eligibility/contractual requirements and minimum-quality-standard/free-entry theory;
- **S / inducement:** public standards can change endogenous innovation/product R&D;
- **F:** participation/implementation/R&D finance changes entry or quality/design cost;
- **R:** future market size and multi-market scope change commonality, modularity and customization;
- **F+R:** supply-push + demand-pull policy mixes are established;
- **multi-site as evidence:** external-validity/site-selection theory already occupies the information reading.

Most importantly, S+F, S+R and F+R already generate the relevant qualitative effects. The audit identified no strategic behavior that first appears only under S+F+R, and the administrative S -> F -> R order does no independent economic work without adding a new commitment/learning/contracting primitive.
